# 统计页多语言页签单行稳定布局优化方案

## 1. 需求与结论

统计顶部的“计划 / 任务 / 四象限 / 标签”四段页签在英文环境中将 `Quadrants` 折成两行，导致页签文字、分段高度与视觉节奏不稳定。

推荐继续使用 Flutter 官方 `SegmentedButton<StatView>`，不替换交互模型；通过“整体等分宽度 + 紧凑的段内水平留白 + 固定的单行标签视口 + 仅在必要时等比缩小文字”解决。这样可以同时保证：

- 五种已支持语言中的四个页签都始终单行、居中显示；
- 分段整体的宽高、边框、圆角、分隔线和选中态不因语言或字号变化；
- 不改动页签文案语义，不使用截断、省略号、不明确缩写或强制换行；
- 不限制全 App 的字号设置，仅对这个空间严格的导航控件做局部布局保护。

## 2. 检查范围

### 2.1 源码范围

- `lib/stats_page.dart`
  - `StatsPage` 顶部的 `SegmentedButton<StatView>` 是问题的唯一直接入口。
  - 四个 `ButtonSegment` 目前都直接使用可自然换行的 `Text`。
- `lib/l10n/ui_text.dart`
  - 项目将 Flutter `Text` 包装为构建时本地化组件，`softWrap` 和 `maxLines` 最终会原样传递给官方 `material.Text`。
  - 因此无需改造全局本地化封装，只需在统计页签上明确单行约束。
- `lib/main.dart` 与 `lib/models.dart`
  - App 可跟随系统文字缩放，也可使用 `0.8–1.4` 的自定义缩放。
  - 本方案不修改这些全局行为。

### 2.2 语言范围

`AppLocalizations.supportedLocales` 和当前显示层共覆盖以下五类用户语言：

| 语言 | 计划 | 任务 | 四象限 | 标签 | 长度风险 |
| --- | --- | --- | --- | --- | --- |
| 简体中文 | 计划 | 任务 | 四象限 | 标签 | 低 |
| 繁体中文 | 計畫 | 任務 | 四象限 | 標籤 | 低 |
| 日语 | 計画 | タスク | 四象限 | タグ | 低 |
| 韩语 | 계획 | 작업 | 사분면 | 태그 | 低 |
| 英语 | Plans | Tasks | Quadrants | Tags | 高，`Quadrants` 是当前最长标签 |

当前翻译本身准确且已经较紧凑，不建议把 `Quadrants` 改成语义不完整的 `Quad`、`4Q` 或与其他页签单复数风格不一致的 `Quadrant`。

## 3. Flutter 官方实现基线

1. [SegmentedButton](https://api.flutter.dev/flutter/material/SegmentedButton-class.html)
   - 官方定位是在 2–5 个选项中切换视图、排序或筛选；当前四个统计视图属于其适用范围。
2. [SegmentedButton.expandedInsets](https://api.flutter.dev/flutter/material/SegmentedButton/expandedInsets.html)
   - 默认使用内容固有宽度；指定 `expandedInsets` 后可填满父级可用宽度。
   - 项目适配：设为 `EdgeInsets.zero`，让五种语言都使用相同的整体宽度和四等分布局，不再由最长翻译决定控件宽度。
3. [SegmentedButton.style](https://api.flutter.dev/flutter/material/SegmentedButton/style.html)
   - 官方允许通过 `ButtonStyle.padding` 调整各分段内边距，同时保留主题的颜色、边框和形状。
   - 项目适配：只覆盖分段内的紧凑留白，不重写前景色、背景色、边框、圆角、水波和动画。
4. [FittedBox](https://api.flutter.dev/flutter/widgets/FittedBox-class.html) 与 [BoxFit.scaleDown](https://api.flutter.dev/flutter/painting/BoxFit.html)
   - `FittedBox` 按约束对子组件缩放；`scaleDown` 在内容已能容纳时不放大，只在内容超出时等比缩小。
   - 项目适配：将它放在页签文字内部作为极端窄屏或大字号下的最后保护，不用来改变整个控件的缩放。
5. [MediaQuery.textScalerOf](https://api.flutter.dev/flutter/widgets/MediaQuery/textScalerOf.html) 与 [Text.textScaler](https://api.flutter.dev/flutter/widgets/Text/textScaler.html)
   - 官方明确文字布局会受用户的系统辅助功能字号策略影响。
   - 项目适配：不在全局禁用缩放，不改动页面内容的可读性；仅让页签的固定视口和 `scaleDown` 吸收尺寸变化。
6. [Flutter 官方 `segmented_button.dart` 源码](https://github.com/flutter/flutter/blob/main/packages/flutter/lib/src/material/segmented_button.dart)
   - 源码中水平分段会使用同一子项宽度；在可用宽度不足时，子项宽度会受总宽度除以分段数的上限约束。当前默认 `Text` 可换行，因此最长英文标签在收紧后变成两行。

## 4. 修改前的情况

1. 统计页左右各有 `18` 的外边距；截图尺寸下可用宽度被四个分段共享。
2. `SegmentedButton` 未设置 `expandedInsets`，宽度主要由各语言标签的固有尺寸和官方默认内边距决定。
3. 四个标签未设置 `maxLines`、`softWrap` 或空间不足时的缩放策略。
4. 英文 `Quadrants` 是最长文案；分段宽度收紧后，它被 Flutter 正常地分成两行。
5. 页签内容高度参与分段按钮的固有高度计算，因此换行或更大的字号会改变外层样式尺寸。
6. 语言数据完整，问题是布局约束缺失，不是翻译缺失。

## 5. 修改后的目标状态

1. 控件始终填满统计页内容宽度，四段等宽。
2. 所有标签始终单行、水平和垂直居中，不换行、不截断、不显示省略号。
3. 标准字号和宽屏下保持当前主题文字尺寸；只在当前标签确实无法容纳时使用 `BoxFit.scaleDown`。
4. 页签标签的可视高度固定，系统超大字号或 App 自定义字号不再撑高分段外框。
5. 主题控制的颜色、字重、边框、圆角、分隔线、点击反馈和选中态保持不变。
6. 读屏语义仍是完整的本地化页签文案，不由视觉缩放值替代。

## 6. 具体修改方案

### 6.1 封装统计视图选择器

在 `lib/stats_page.dart` 内抽取私有组件 `_StatViewSelector`，集中管理：

- `StatView` 到中文源文案的唯一映射；
- `SegmentedButton` 的等宽、内边距和选中事件；
- 单行标签布局。

这是统计页四个视图的唯一选择入口，不复制第二套样式。

### 6.2 让分段控件在所有语言下同宽

为 `SegmentedButton` 设置：

```dart
expandedInsets: EdgeInsets.zero,
```

官方组件将填满当前父级宽度，四个分段等分，从而消除短文案语言和长文案语言之间的整体宽度差异。

### 6.3 只收紧段内留白，不重写外观

使用 `SegmentedButton.styleFrom` 或等价 `ButtonStyle` 只设置段内 `padding`，建议初始基线为水平 `6`、垂直 `8`。该数值不是对不同语言逐个打补丁，而是基于最窄支持宽度下四等分单元的统一约束。

不覆盖以下属性：

- `foregroundColor` / `backgroundColor`；
- `side` / `shape`；
- `textStyle`；
- `overlayColor` / `animationDuration` / `splashFactory`。

因此浅色、深色和选中状态仍完全由当前 `ThemeData` 与 Flutter 官方组件控制。

### 6.4 为标签建立固定单行视口

新增私有展示组件 `_StatViewLabel`，结构原则如下：

```dart
SizedBox(
  height: 20,
  child: FittedBox(
    fit: BoxFit.scaleDown,
    alignment: Alignment.center,
    child: Text(
      source,
      maxLines: 1,
      softWrap: false,
    ),
  ),
)
```

具体效果：

- `maxLines: 1` 和 `softWrap: false` 明确禁止标签换行；
- 固定高度让分段外框不受字体缩放撑高；
- `BoxFit.scaleDown` 只对宽度或高度超限的标签等比缩小，能容纳时不放大、不改变当前字体风格；
- 不设置 `TextOverflow.ellipsis`，避免 `Quadrants` 变成无法分辨的部分文字；
- 延续使用项目现有本地化 `Text` 封装，不新建重复的 locale 映射。

`20` 是页签文字可视行高的建议基线，配合官方分段按钮的默认最小高度和点击区。实施时不应根据单个语言增加专用高度或专用字号。

### 6.5 字号与可访问性边界

不推荐在统计页甚至全 App 使用 `MediaQuery.withNoTextScaling`，因为这会忽略用户的辅助功能设置。

推荐边界是：

- 页面标题、统计卡片、图表、空状态等内容继续完整响应全局 `TextScaler`；
- 顶部四段导航保留完整语义，但在固定单行视口内局部自适应；
- 极端大字号下，页签文字可能因 `scaleDown` 无法按用户倍率继续变大，这是“保持四段导航单行且外观不变”的必要取舍；
- 读屏仍可读取完整的本地化标签。

## 7. 不采用的方案

1. **仅把 `Quadrants` 改短**
   - 只能遮蔽英文问题，不能解决系统大字号或未来翻译变长。
2. **使用省略号**
   - 页签是核心导航，截断后会损失含义，不符合界面文案精确原则。
3. **让整个分段控件随字号变高**
   - 虽然保留了大字，但会继续破坏四段控件的稳定外观，与本次目标相反。
4. **换成横向滚动页签**
   - 会让部分统计视图不可同时看到，并改变当前直接切换交互。
5. **自定义绘制分段控件**
   - Flutter 官方已有适用的 `SegmentedButton`，没有必要重新实现手势、语义、焦点和选中状态。
6. **在全局关闭或截断文字缩放**
   - 会影响其他页面和辅助功能用户，修改范围明显过大。

## 8. 实施顺序

1. 在 `stats_page.dart` 中增加 `_StatViewSelector` 和 `_StatViewLabel` 私有组件。
2. 将现有内联 `SegmentedButton<StatView>` 替换为 `_StatViewSelector`，保留 `_selectView`、`PageController` 和左右滑动同步逻辑。
3. 配置 `expandedInsets: EdgeInsets.zero` 和统一紧凑内边距。
4. 四个标签统一改用单行、固定高度、`scaleDown` 的标签组件。
5. 不修改翻译表、统计数据、视图切换、页面滑动或筛选逻辑。

## 9. 人工验收矩阵

根据项目约束，本方案不新增测试代码，不执行构建或自动测试。实施后由用户按以下矩阵手工验收：

### 9.1 语言

- 简体中文：`计划 / 任务 / 四象限 / 标签`；
- 繁体中文：`計畫 / 任務 / 四象限 / 標籤`；
- 日语：`計画 / タスク / 四象限 / タグ`；
- 韩语：`계획 / 작업 / 사분면 / 태그`；
- 英语：`Plans / Tasks / Quadrants / Tags`。

### 9.2 字号

- App 自定义 `80%`、`100%`、`140%`；
- 跟随系统的默认文字大小；
- 跟随系统的较大和最大辅助功能文字大小。

### 9.3 可用宽度与外观

- 窄屏 iPhone 级别宽度（以 `320` 逻辑像素为下限基线）；
- 常见 `375`、`390`、`430` 逻辑像素宽度；
- iPad 或横屏宽度；
- 浅色与深色主题；
- 四个页签逐一选中，确认颜色、边框、分隔线、圆角、按压反馈和页面滑动同步未变。

### 9.4 验收标准

- 任何支持语言下，页签文字均为一行；
- 不出现黄黑溢出条、文字裁切、省略号或字符缺失；
- 五种语言、各字号下的分段外框高度与视觉样式一致；
- 四个分段等宽，整体宽度与统计页内容区一致；
- 点击切换和横向滑动 `PageView` 后，页签选中态始终与当前页一致；
- VoiceOver 读取的是完整页签名称和选中状态。

## 10. 可能影响与注意事项

1. 改动仅影响统计顶部四段页签的布局，不影响统计口径、数据库、筛选条件或其他页面。
2. `expandedInsets: EdgeInsets.zero` 会让原本可能按内容收缩的短文案控件稳定为占满内容区；这是保持语言间样式一致的预期变化。
3. 极端大字号下，空间约束会使页签文字被局部缩小；页面其他文字仍正常响应用户字号。
4. 标签固定高度与段内边距必须作为统一常量管理，不得为英文或单个设备单独分支。
5. 后续若新增语言，应将新语言的四个页签加入同一人工验收矩阵，而不得通过专用缩写规避布局。

## 12. 实施结果（2026-10-27）

### 修改前的情况

- `lib/stats_page.dart` 在 `StatsPage` 内直接声明四个 `ButtonSegment`。
- 分段控件按内容固有宽度参与布局，没有明确要求填满统计页内容区。
- 页签文字没有单行限制，也没有窄屏和大字号下的缩放保护。
- 英文 `Quadrants` 在截图所示宽度下换成两行，并改变分段控件高度。

### 修改后的情况

- 新增 `_StatViewSelector`，统一承载统计页四个视图的官方 `SegmentedButton`。
- 设置 `expandedInsets: EdgeInsets.zero`，使控件填满父级可用宽度并保持四段等宽。
- 段内边距统一为水平 `6`、垂直 `8`，不覆盖主题颜色、边框、圆角和交互状态。
- 新增 `_StatViewLabel`，使用固定 `20` 高度、单行文本与 `FittedBox(BoxFit.scaleDown)`。
- 原有 `_selectView`、`PageController`、点击切换和横向滑动同步逻辑保持不变。

### 修改内容

- 修改 `lib/stats_page.dart`：
  - 将内联分段控件替换为 `_StatViewSelector`；
  - 新增统一页签标签组件 `_StatViewLabel`；
  - 四个语言源文案继续使用现有本地化 `Text` 包装，不修改翻译表。
- 更新本文档：记录实际实施结果。

### 修改原因

- 从布局层消除英文长标签换行问题，而不是通过缩写或修改翻译规避问题。
- 让简中、繁中、日语、韩语和英语共享同一套组件尺寸与交互样式。
- 避免系统或 App 字号变化撑高分段外框，同时不影响统计页面其他内容响应文字缩放。

### 可能影响或注意事项

- 统计页签现在会稳定占满统计内容区宽度，这是预期视觉变化。
- 极端大字号或极窄宽度下，页签文字会在固定单行视口内等比缩小；不会换行或显示省略号。
- 本次没有修改全局字体缩放、翻译、统计计算、筛选条件、数据库或其他页面。
- 按项目约束未执行构建、编译、静态分析或自动化测试；需要按第 9 节矩阵进行人工验收。
