# v1 源码迁移至 v2

## 任务目标

将 `v1` 中已经接近稳定的 Flutter/iOS 项目迁移到 `v2` Git 仓库，仅保留适合提交到 GitHub 的必要源码、工程配置和资源文件。

## 修改前的情况

- `v1` 是完整的 Flutter/iOS 应用工作目录，同时包含源码、本地缓存、构建产物、IDE 配置、Xcode 用户数据和 Flutter 自动生成文件。
- `v2` 是已有 Git 仓库，迁移前仅跟踪 `.gitignore` 和占位 `README.md`。
- `v2` 中已有本地 `.idea` 目录，但该目录受忽略规则保护且未被 Git 跟踪。

## 修改后的情况

- `v2` 已包含 Flutter 项目根配置、依赖锁文件、Dart 源码以及必要的 iOS 工程文件和应用资源。
- `v2/.git` 与原有 Git 历史保持不变。
- `v2/.gitignore` 已替换为与 `v1` Flutter 项目一致的忽略规则。
- 本地缓存、构建产物、IDE 配置和可重新生成的文件未从 `v1` 迁移。

## 修改内容

### 已迁移

- 根目录文件：`.gitignore`、`.metadata`、`README.md`、`analysis_options.yaml`、`pubspec.yaml`、`pubspec.lock`。
- Dart 源码：`lib/` 下全部文件。
- iOS 工程源码与资源：`ios/.gitignore`、`ios/Flutter` 中的静态配置、Xcode 工程与共享配置、`ios/Runner` 中的 Swift/Plist/Storyboard/资源文件、`ios/RunnerTests`。

### 未迁移

- Flutter/Dart 本地状态：`.dart_tool/`、`.flutter-plugins-dependencies`。
- 构建产物：`build/`。
- IDE 和用户态文件：`.idea/`、`*.iml`、`.DS_Store`、Xcode `xcuserdata/`。
- Flutter/iOS 自动生成文件：`ios/Flutter/Generated.xcconfig`、`ios/Flutter/flutter_export_environment.sh`、`ios/Flutter/ephemeral/`、`ios/Runner/GeneratedPluginRegistrant.*`。
- `v1/docs/vibe/` 下的历史实施记录，因为它们不是应用运行所需源码；本次迁移记录单独写入 `v2/docs/vibe/`。

## 修改原因

- 保证 `v2` 获得应用所需源码和平台工程配置。
- 避免提交与本机环境绑定、体积较大或可由 Flutter 工具重新生成的内容。
- 保持仓库内容接近常规 GitHub 源码仓库的最小可维护集合。

## 可能影响与注意事项

- 首次在 `v2` 中打开或运行项目前，需要由维护者手动获取依赖，并让 Flutter/Xcode 重新生成被排除的文件。
- `v2` 原有本地 `.idea` 目录未删除；它仍被 `.gitignore` 忽略，不会进入 Git 提交。
- 按项目约束，本次未执行构建、编译、打包或自动化测试；功能与构建结果需由维护者手动验证。
- 所迁移文本文件保持原有编码和换行风格；新建本文档使用 UTF-8 无 BOM、LF 换行。
