# 统计页 `Semantics` 编译错误修复

## 问题现象

Xcode 构建 Flutter iOS 应用时，`lib/stats_page.dart:1782` 报错：不能在常量表达式中调用非 `const` 构造函数，随后 `kernel_snapshot_program` 与打包流程失败。

## 官方实现依据

- Flutter 官方 `Semantics` 主构造函数文档：<https://api.flutter.dev/flutter/widgets/Semantics/Semantics.html>
- 官方文档明确说明当前 `Semantics(...)` 主构造函数不是常量构造函数；如需创建常量实例，应使用 `Semantics.fromProperties`。

## 修改前

空数据分支使用 `return const Semantics(...)`。当前 Flutter SDK 中 `Semantics(...)` 不是 `const` 构造函数，因此编译失败。

## 修改后

空数据分支改为 `return Semantics(...)`，内部的标签、语义值、`excludeSemantics` 和 `_StatisticsEmpty` 子组件均保持不变。

## 修改内容

- 移除 `Semantics(...)` 调用前的 `const`。
- 未调整统计逻辑、界面结构、文案或无障碍语义内容。

## 修改原因

该位置并不要求整个 `Semantics` 实例成为编译期常量。移除外层 `const` 是符合当前 Flutter 官方 API 的最小修复，也无需为了常量化改写为更冗长的 `Semantics.fromProperties`。

## 可能影响与注意事项

- 预期仅消除该编译错误，不改变运行时界面和交互行为。
- 按项目约束，本次未执行构建、编译或自动化测试；需由用户手动重新构建确认。
