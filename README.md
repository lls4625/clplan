# ClPlan

基于 Flutter 的本地计划与任务管理应用，当前以 iOS 为主要目标平台。

## 当前能力

- 全年日历、日期计划摘要与双指间距调整
- 按起止日期建立计划，并在计划内管理具体任务
- 计划和任务分开统计，支持周、月、季度、半年和年度周期
- 自定义状态、主题、字号、语言偏好和表格列配置
- SQLite 离线持久化，不声明数据库外键
- XLSX 导入、导出和同 ID 逐字段冲突确认

## iOS 标识

- Bundle ID：`vip.ichiki.javalee.clplan`
- 显示名称：`ClPlan`

## 数据说明

数据库文件名为 `clplan.sqlite3`。`PlanItem` 表示对外展示的计划，`TaskItem` 表示计划内的具体执行任务，任务通过 `plan_id` 关联所属计划。历史数据中的 `parent_task_id` 仍保留用于兼容。
